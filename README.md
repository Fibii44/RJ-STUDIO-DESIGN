## 🏛️ About the Project
This is a bespoke **Architectural Project Management and Scheduling System** built for **RJ Design Studio**. The platform serves as a bridge between the architect and the client, allowing for seamless communication, project tracking, and appointment booking.

### **Core Aesthetic**
The UI is designed with a "Boutique" architectural feel, utilizing a warm palette of **Linen, Sand, and Earthy Browns** to reflect a professional and sophisticated design studio environment.

---

## ✨ Key Features
- **Luxury Landing Page:** Showcases recent architectural archives with a modern, high-end feel.
- **Secure Client Portal:** Custom-themed Login and Registration for project partners.
- **Appointment Scheduling:** (In Development) Allows clients to book site visits and consultations.
- **Project Archives:** A preview of residential and commercial projects for prospective clients.

---

## 🛠️ Tech Stack
This project leverages the **TALL/VILT** stack variant for high performance and modern reactivity:

- **Framework:** [Laravel 11+](https://laravel.com)
- **Frontend:** [Vue.js 3](https://vuejs.org/) with **Inertia.js**
- **Authentication:** [Laravel Jetstream](https://jetstream.laravel.com)
- **Styling:** [Tailwind CSS](https://tailwindcss.com) (Custom Earth Tone Palette)
- **Build Tool:** [Vite](https://vitejs.dev/)
